Ex. 1 — Riemann and Lebesgue integration

1.1 Two ways of slicing the area

Riemann partitions the domain [a, b] into subintervals [xi−1, xi], picks a tag ξi in each one and adds up vertical strips. The integral exists when every choice of tags gives the same limit as the mesh goes to 0 (equivalently, the upper and lower Darboux sums meet).

R(f, P, ξ) = Σi f(ξi)·(xi − xi−1)  →  ∫ab f(x) dx

Lebesgue partitions the range into levels y0 < y1 < … < yK, asks "where does f take values in this band?" and weights each band by the measure of its preimage. The approximating functions are simple functions (finitely many values on measurable sets), and the integral is the supremum of their integrals:

L(f, y) = Σj yj·μ( { x : yj ≤ f(x) < yj+1 } )
= y0·μ(E) + Σj Δy·μ( { x : f(x) > yj } )    (layer-cake form, f ≥ y0)
→ ∫ f dμ = y0·μ(E) + ∫y0∞ μ{f > t} dt

The classic image: Riemann counts a pile of coins in the order they come out of the pocket; Lebesgue first sorts them by value and counts how many of each. Every Riemann-integrable function is Lebesgue integrable with the same value; the converse is false (Dirichlet). Lebesgue's criterion: a bounded f is Riemann integrable if and only if its set of discontinuities has measure zero.

1.2 The numerical methods

With a "budget" N we compare five methods (source: labs/static/labs/lab6/integrate.js):

MethodWhat it doesFunction evaluations
Riemann, left / midpoint tagsN equal subintervals, tag at the left end or the centreN

Lebesgue, level setsN equal bands of the range; the set {f > tj} is found exactly by tabulating f on N cells and locating every crossing f = tj by bisection; its measure is the total length of the intervalsN + 40–50 per crossing
Lebesgue, Monte Carlo measureN bands; μ{f > tj} ≈ L·#{i : f(Ui) > tj}/N from N uniform random points (sort the values once, then one binary search per level)N

A subtlety for the pathological functions: every floating-point number is a (dyadic) rational, so Dirichlet(0.3) cannot be decided from the double 0.3. Each sample point therefore carries a tag: a grid point i/N is the rational with denominator N/gcd(i, N), while a uniformly random point is a generic real, i.e. irrational. This is exactly the information the mathematics uses.

1.6 Discussion

  • Riemann-integrable functions: both approaches converge to the same value. The table shows all five columns agreeing with the exact integral for the first eight functions; this is the theorem "Riemann integrable ⇒ Lebesgue integrable, with the same integral".
  • Smooth functions (sin x, x², sin x/x): the midpoint Riemann sum has error O(N⁻²) and is the clear winner. The level-set Lebesgue sum is the midpoint rule applied to t ↦ μ{f > t}; this function has a square-root singularity wherever f has a maximum (e.g. μ{sin x > t} = π − 2 arcsin t), so the error is only O(N⁻¹·⁵), and every level costs extra bisections. Left sums are O(N⁻¹); random tags behave like stratified sampling.
  • Simple and piecewise-linear functions (the two steps, |x − 0.5|): the Lebesgue sum is exact up to rounding for every N, because μ{f > t} is piecewise constant or linear in t and bisection finds the jump exactly. Step functions are the "atoms" of the Lebesgue theory. Riemann sums are exact only when the jump falls on a grid point; for N = 31, 3162 their error is O(1/N) (one cell straddles the jump).
  • Unbounded 1/√x: the Riemann integral exists only as an improper limit; the left sum evaluates f(0) = ∞ and fails. The Lebesgue integral needs no special treatment in theory (μ{f > t} = 1/t² for t ≥ 1, and ∫0∞ μ{f > t} dt = 2), but numerically the range has to be truncated at some height T, losing ∫T∞ t⁻² dt = 1/T. All methods converge like N⁻¹ᐟ²; Monte Carlo is the worst here because Var f(U) = ∞.
  • Oscillating sin(1/x): infinitely many oscillations near 0; it is Riemann integrable (bounded, one discontinuity) but every method converges slowly. The level sets are infinite unions of intervals, so the level-set method needs huge numbers of bisections (see the evaluation count): partitioning the range is expensive when preimages are complicated.
  • Dirichlet function: the methods disagree, and that is the point. Rational tags (left, midpoint, and the rational grid of the level-set method) give 1; generic tags give 0. Since every partition can be tagged both ways, upper Darboux sums are 1 and lower ones 0 for every N: the Riemann integral does not exist. In Lebesgue's theory {f = 1} = ℚ ∩ [0, 1] is countable, hence of measure 0, and ∫ f dμ = 1·μ(ℚ∩[0,1]) + 0·μ(irrationals) = 0. The Monte Carlo measure gets this right because a random point hits a rational with probability 0; the grid-based level-set method gets it wrong because a finite grid only ever sees rationals: a numerical method cannot see a set of measure 0 unless it lands on it.
  • Thomae function: discontinuous at every rational but continuous at every irrational. The discontinuities have measure 0, so it is Riemann integrable, with integral 0. Random tags give 0 at once; rational tags give Σ gcd(i, N)/N², which tends to 0 slowly (roughly like N⁻¹ log N). Both theories agree.
  • Efficiency: in one dimension, partitioning the domain is cheaper. A Riemann sum costs one evaluation per cell; the level-set method costs O(N) evaluations to tabulate plus bisections for every crossing, and O(N·K) bookkeeping (it is 100–1000× slower at N = 10⁴). Lebesgue's idea pays off theoretically (limits, convergence theorems, general measure spaces such as probability spaces) and numerically when f is simple, or when the domain is high-dimensional and only Monte Carlo sampling is feasible.

Ex. 2 — Numerical computation of the normal CDF

2.1 The problem

Φ(x) = ∫−∞x φ(t) dt,    φ(t) = e−t²/2 / √(2π)

By symmetry Φ(−x) = 1 − Φ(x) and Φ(0) = 1/2, so it is enough to compute ∫0x φ. See Hogg–McKean–Craig, §3.4 (the normal distribution) for the derivation of the density and the use of the table of Φ.

2.2 Why Φ is not an elementary function: Liouville's theorem

An elementary function is one built from rational functions, exp, log, roots and the trigonometric functions by finitely many arithmetic operations and compositions. Liouville (1835) proved a structural theorem about their antiderivatives; a special case, enough here, is:

Theorem (Liouville). Let f, g be rational functions, g non-constant. Then ∫ f(x)·eg(x) dx is elementary
if and only if there is a rational function R(x) with   f = R′ + R·g′,   and then ∫ f·eg dx = R·eg + C.

For the normal density take f = 1, g = −x²/2. We would need a rational R with

R′(x) − x·R(x) = 1.
  • If R had a pole of order k ≥ 1 at some a ∈ ℂ, then R′ has a pole of order k + 1 at a while x·R has order at most k; nothing can cancel it, but the right side 1 has no pole. So R is a polynomial.
  • If R is a non-zero polynomial of degree d, then x·R has degree d + 1 and R′ degree d − 1, so the left side has degree d + 1 ≥ 1 ≠ 0 = deg 1. And R = 0 gives 0 = 1.

No such R exists, so ∫ e−x²/2 dx is not an elementary function, and neither is Φ. The integral is perfectly well defined (and ∫−∞∞ e−x²/2 dx = √(2π) can be computed in closed form with the polar-coordinates trick), but the function x ↦ Φ(x) has no finite formula. The same argument shows that ex/x, sin x/x and 1/log x have no elementary antiderivatives.

2.3 The error function

The way out is to give the missing antiderivative a name. The error function is

erf(z) = (2/√π) ∫0z e−t² dt,    erfc(z) = 1 − erf(z),    and with t = s/√2:
Φ(x) = ½·[1 + erf(x/√2)] = ½·erfc(−x/√2)

This is an exact analytic representation, in the same sense in which log x = ∫1x dt/t is: once erf is accepted as a "special function" with known properties (odd, increasing, erf(∞) = 1, derivative (2/√π)e−z², series and asymptotic expansions) we can manipulate Φ symbolically. But a name is not a number: to get the digits of erf(1.3) someone must still evaluate a series, a continued fraction or a quadrature, exactly as for log or sin. Libraries do it once, carefully (C's erf/erfc, Python's math.erf, scipy.special.ndtr). JavaScript has no Math.erf, so here we must build it.

Trapezoid / SimpsonΦ(x) = ½ + ∫0x φ with n subintervalssimple, general; error O(n⁻²) / O(n⁻⁴); cost grows with n; absolute (not relative) accuracy in the tails

Marsaglia seriesΦ(x) = ½ + φ(x)·(x + x³/3 + x⁵/(3·5) + …)integration by parts; all terms positive, so no cancellation in the sum; accurate to ~10⁻¹⁶ absolutely, but ½ − … loses relative accuracy for very negative x
Laplace continued fraction1 − Φ(x) = φ(x) / (x + 1/(x + 2/(x + 3/(x + …))))excellent relative accuracy in the tails, converges faster as x grows; slow near 0
Hybrid (our method)compute the small tail Q = Φ(−|x|): Marsaglia for |x| < 2.5, continued fraction for |x| ≥ 2.5; return Q or 1 − Q≈ 10⁻¹⁶ absolute and ≈ 10⁻¹⁴ relative error on all of [−8, 8], at most ~70 iterations
 
// The hybrid method (labs/static/labs/lab6/normal.js)
function cdf(x) {
  const a = Math.abs(x);
  const q = a < 2.5 ? 0.5 - phi(a) * marsagliaSum(a)   // centre: series with positive terms
                    : tailCF(a).value;                  // tails: Laplace continued fraction (Lentz)
  return x < 0 ? q : 1 - q;                            // Φ(x) = Q or 1 − Q
}

2.8 Conclusions

  • Quadrature works and its convergence rates are exactly the theoretical ones (slopes −2 and −4 on the log–log plot, Simpson reaching 10⁻¹⁴ with about a thousand subintervals), but it costs n exponentials per value and only controls the absolute error: for Φ(−8) ≈ 6·10⁻¹⁶ it computes ½ − 0.49999… and returns garbage relative to the true value.
  • The erf power series is exact in principle but, being alternating, it adds terms that grow like ez² to get a result below 1: at x = 8 the largest term is ≈ 6·1011, so about 12 of the 16 available digits are lost. Fine for |x| ≲ 2, unusable in the tails.
  • A–S 7.1.26 is the fastest (one exponential and a degree-5 polynomial) and good enough for many statistical uses (7 digits), but its accuracy is fixed and its relative error in the tails is poor.
  • The hybrid combines a series without cancellation (centre) and the continued fraction (tails) and always computes the smaller of Φ(x) and 1 − Φ(x) directly: every reference value is reproduced to within a few units in the last place, at roughly the cost of a hundred floating-point operations. This is the same design used by production libraries (e.g. Cody's rational approximations behind erfc): different formulas on different ranges, and the tail computed as a tail.
  • So the special function erf gives Φ an exact name and exact properties, while Liouville's theorem guarantees that no finite elementary formula exists: numerical approximation is not a shortcut but the only way to obtain the numbers.
